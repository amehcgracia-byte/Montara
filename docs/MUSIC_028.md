# Show music: eight tracks and YouTube import

The Music dialog now supports audio uploads, the bundled library, and public YouTube links. URL imports reuse the existing bounded audio-reference downloader in a background job, with an importing indicator, error reporting, a single active import per session, temporary-file cleanup, and an explicit user-rights label. Only YouTube hostnames are accepted; arbitrary internet/private-address URLs are rejected. Service access checks can still reject a link: users can upload their audio instead. Importing a song does not confer a licence.

Six complete Kevin MacLeod tracks were added under CC BY 4.0 (official attribution template and catalogue evidence saved in tests/fixtures/music): Sneaky Snitch, Monkeys Spinning Monkeys, Investigations, Local Forecast, Carefree, Airport Lounge. Together with the existing two CC0 tracks the library has eight songs. Each song identifies its author, source and licence; selecting CC BY music explicitly asks the editor to publish the attribution. The existing downloadable credits include title/author/source/licence and the edit notice. No paid stock subscription was purchased, and the advertisement soundtracks were not changed.

Verification: four real-media tests pass (catalogue, byte-range playback, placement/volume/timing/removal/credits, rendered preview with audio-spectrum verification, and background-link success/failure/private-host rejection). YouTube download was also exercised without a mock using the user's All Minds link bfGH-664RQ4 on the local service. The actual browser Music dialog displayed the songs, selected a CC BY song with attribution, and completed a YouTube import. Remote YouTube access may vary by provider/IP and is not guaranteed by that local result. No editor/mixer engine code changed.

Public verification: stable Vercel deployment serves v0.28, eight catalogue tracks (six CC BY, two CC0), and the link UI. The real All Minds YouTube link was rejected on the public worker with a service verification requirement, while succeeding locally. This is an explicitly disclosed external-service limitation; it was not bypassed. Uploading the audio remains available.
