# Vercel demo source

This is the source of the current public preview, not a static replacement editor.
Run `npm ci` and `npm run build` here to regenerate the overlay from repository files.
The API uses Vercel Sandbox and a pinned template snapshot. The snapshot ID and Drive
names in runtime.js belong to the owner's account. Provision compatible resources
before deploying elsewhere. No credentials or local .vercel link are included.
Do not deploy automatically or change the stable montara-tau.vercel.app alias.
Public media and ads are examples with rights/voice licensing still to review.
